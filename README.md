# Study Bench

Exam revision platform for DCU Year 3 engineering modules: topic walkthroughs, formula sheets, tutorial and past-paper questions with worked solutions, an MCQ drill and a work-orders (deadlines) list.

Open it at **https://dnl-oconnell.github.io/study-bench/** and use your browser's *Install* option to add it as an app.

Progress, ticks and work orders are saved in the browser you use.
